# check_stack_sizes allowlist — variant: tests
#
# Frames above STACK_SIZE_THRESHOLD (2048 B) that are permitted, each capped
# at its measured size so growth still fails.
#
#     scripts/check_stack_sizes.sh --variant tests --emit-allowlist builddir/kernel-tests.elf
#
# Every entry must match at least one over-threshold frame; a dead exemption
# fails the gate. No entry may exceed the 4096 B guard page.
#
# There are deliberately no entries for test functions. Test code runs on the
# same 32 KiB task stacks as everything else, so it lives under the same
# ceiling; a frame that exceeds it is refactored, not exempted.

# Tens of thousands of records. See the dev allowlist for why the floors are
# set relative to the other variants' counts.
min-records 30000

# The kernel/tests image registers thousands of tests; a dev or release ELF
# trips here.
expect-test-registry many
