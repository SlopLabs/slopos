# The private call surface behind slopos_abi::BASE_INTERFACE. Data for
# scripts/check_base_interface.sh.
#
# The surface is every SlopOS-private syscall's number and signature, the abi
# items those signatures name or the calls' docs link, everything reachable
# from them through field and alias types — and the `root` globs below, for
# what a call reads or writes that its signature cannot name: records behind
# a byte buffer, op and flag families, wire-packing helpers. A glob matches
# `::`-joined canonical paths, inherent members included
# (`slopos_abi::ring::*` takes `RingLayout::new`'s offsets too). A glob that
# matches nothing fails as dead. Never root slopos_abi::base_interface: the
# number cannot digest itself.
#
# Below the roots, the ledger: `interface <n> <sha256 of the surface>`, oldest
# first, contiguous from 1, appended only by `check_base_interface.sh
# --record`. A row is never rewritten: a changed surface takes the next number.
